# Origen Mate

Sitio web moderno y responsivo para **Origen Mate**, emprendimiento argentino de venta minorista de yerbas mate con envíos a domicilio desde Paraná, Entre Ríos.

## 📋 Características

- ✨ **Diseño moderno y minimalista** con paleta de colores verde/madera
- 📱 **Completamente responsive** para mobile, tablet y desktop
- ⚡ **Animaciones suaves** al scroll y transiciones fluidas
- 📲 **Integración con WhatsApp** para consultas directas
- 🎯 **SEO básico optimizado** con meta tags y estructura semántica
- ♿ **Accesible** con aria-labels y navegación clara
- 🚀 **Compatible con GitHub Pages** lista para deployar

## 🎨 Secciones

1. **Hero Section** – Logo, nombre, frase destacada y CTA principal
2. **Sobre Nosotros** – Descripción de la marca y diferenciales
3. **Productos** – Cards con 5 yerbas destacadas con imágenes
4. **Contacto** – Formulario elegante y links de contacto
5. **Footer** – Instagram, ubicación y cierre

## 🚀 Cómo usar

### Localmente

1. Clona o descarga el repositorio
2. Abre el archivo `index.html` en tu navegador
3. O usa un servidor local:
   ```bash
   python -m http.server 8000
   # Luego abre http://localhost:8000
   ```

### En GitHub Pages

1. Sube el repositorio a GitHub
2. Ve a Settings → Pages
3. Selecciona `main` branch como source
4. ¡Listo! Estará en `https://tu-usuario.github.io/origenmate`

## 🔧 Tecnologías
